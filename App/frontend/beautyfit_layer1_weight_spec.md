**BeautyFit   Layer 1 规格**

参数权重详细规格 v1.0  |  6个维度 × 参数权重 × 三档区间 × 完整算例

本文档定义 Layer 1 的完整评分逻辑：将 dlib 68-pt 衍生的 landmark 参数，通过各维度权重表转化为6个维度得分（0–100分）。权重反映该参数对该维度视觉贡献程度——在最佳区间时，它能多大程度上让观者「看出来」是这个风格。

**评分公式与系数规则（所有维度通用）**

| 计算步骤 | 具体说明 |
| --- | --- |
| Step 1  区间判断 | 将每个参数值与该维度权重表的★★★ / ★★ / ★ 三档区间比对，找到命中档位。 |
| Step 2  系数映射 | ★★★ 最佳区间 → 系数 1.00 ★★  可接受   → 系数 0.60 ★    需调整   → 系数 0.20 未命中任何区间 → 系数 0.00 |
| Step 3  加权得分 | param_score = 权重(%) × 系数 示例：eye_aspect_ratio 权重 22%，命中★★ → 22 × 0.60 = 13.2 分 |
| Step 4  维度得分 | dimension_score = Σ param_score（所有参数累加） 满分 = 所有参数均命中★★★ = 100 分（权重之和 = 100%） |
| 输出 | 每个维度独立输出一个 dimension_score（0–100），供 Layer 2 风格匹配使用。 |

区间系数说明：★★★（1.00）= 天然适合，不需技法干预；★★（0.60）= 需1–2步调整可达效果；★（0.20）= 存在明显挑战，需专项技法；未命中任何区间（0.00）= 该参数不在此维度的考量范围内。

**甜美  **Sweet

*核心驱动：眼型圆润感（22%）  |  眼 × 脸型 × 唇主导，鼻部权重最低（6%）*

*▸  权重分配逻辑：甜美感的第一判断来源是眼睛——圆眼（eye_aspect_ratio）权重22%远高于其他维度对该参数的权重，因为甜美感最强的视觉信号就是「大眼睛」的无辜感。第二是眼角方向（16%），轻下垂/水平比上扬更温柔。鼻梁高度（6%）对甜美的影响最小——这个参数主要影响立体感和强势感，不是甜美感的核心区分器。*
