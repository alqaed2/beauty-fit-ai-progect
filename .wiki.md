# Project Summary
BeautyFit is an AI-driven beauty analysis platform that enhances user experiences by offering personalized makeup recommendations tailored to individual facial features. Users can upload selfies to virtually try on different lipstick shades in real-time, making informed beauty choices. The platform includes a "Share Card," a beauty insights blog, and subscription plans with payment processing via Stripe. Recent updates have focused on improving the "Find Shade" feature, enhancing user interaction, and optimizing backend performance.

# Project Module Description
The project consists of two main modules: a backend service for image processing and a frontend application for user interaction.

## Functional Modules:
- **Backend**:
  - Face analysis service using MediaPipe's landmark detection.
  - API endpoints for landmark coordinates and analysis results.
  - Enhanced classification logic for face shapes and makeup simulation via OpenAI's API.
  - Pro tutorial generation service from style guides.
  - New endpoint for stylizing user-uploaded images.
  - Performance tracking logs and timeout settings for AI calls.
  - User-friendly messages for `insufficient_ai_balance` errors.
  - Automatic image downscaling for uploads.
  - **Stripe payment integration** with updated endpoints.
  - **Lipstick data API** for serving lipstick records with filtering, pagination, duplicate search, semantic search, and skin-tone recommendation.
  - **New endpoint** for searching lipsticks by color with a **keyword query parameter**.
  - **Health check endpoint** at `/health` for monitoring backend status.

- **Frontend**:
  - User interface for image uploads and results display.
  - Dynamic routing with ScrollToTop functionality.
  - Improved error handling and retry logic for API calls.
  - New layout for Pro tutorial with images and thumbnails.
  - Enhanced user experience features, including progress feedback and "Reuse Last Upload" button.
  - Updated "Complete Report" with style images and sub-style tutorials.
  - Blog section for SEO-optimized articles.
  - Integrated analytics tools for tracking.
  - **Payment gating** in ResultsPage with Stripe checkout buttons.
  - **New Checkout Plan page** for subscription options.
  - **Loading states and error handling** improvements for checkout.
  - **Updated Google AdSense integration** removed for a cleaner interface.
  - **New promotional images** in the `/public/promo/` directory.
  - **Updated payment flow** for direct access to Pro tutorial content.
  - **Caching for Pro tutorial results** and a **History page** to track previously generated reports.
  - **New "Lipstick Fit" feature** allowing users to upload selfies and try on lipsticks.
  - **Color Universe** and **Find Shade** features integrated into the Lipstick Fit page, enhancing lipstick browsing options.
  - **Improved Lipstick Fit page** with horizontal card layouts, scroll management, and personalized recommendation features.
  - **Keyword search functionality** added in the Category tab for the Lipstick Fit page.

# File Description Inventory
- **app/backend/**: Contains backend service files, configurations, models, routers, and services for facial analysis, Pro tutorial generation, payment processing, and lipstick data API with enhanced features.
- **app/frontend/**: Contains frontend application files, including components, pages, and styles for user interaction, focusing on image handling, Pro tutorial promotion, blog content, and payment integration.

# Technology Stack
- **Backend**: Python, FastAPI, dlib, SQLAlchemy, MediaPipe, OpenAI API, python-docx, Pillow
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Axios, html2canvas, qrcode.react

# Usage
To set up the project, follow these steps:
1. **Install Dependencies**:
   - Navigate to the `app/backend` directory and run:
     ```
     pip install -r requirements.txt
     ```
   - Navigate to the `app/frontend` directory and run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - For the backend, run:
     ```
     python main.py
     ```
   - For the frontend, run:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend server.
   - Start the frontend application.
